# Linear Regression Analysis: Education vs Crime Rate

A simple linear regression project exploring the relationship between education levels and crime rates using Python.

## About

This project investigates whether higher education levels correlate with lower crime rates. Using a dataset of 47 observations, I built a simple linear regression model to quantify the relationship and visualize the findings.

### Key Findings

- **Negative correlation** between education and crime — as education increases, crime tends to decrease
- The model captures a meaningful trend with statistical significance
- Residual analysis confirms reasonable model assumptions

## What's Inside

| Step | Description |
|------|-------------|
| Data Creation | Generates the CSV dataset with education and crime data |
| EDA | Statistical summary, data shape, and initial exploration |
| Scatter Plot | Visualizes the raw relationship between variables |
| Model Training | Fits a `LinearRegression` model using scikit-learn |
| Regression Plot | Plots the best-fit line over the data points |
| Model Metrics | Slope, intercept, R², correlation, MSE, RMSE |
| Residual Analysis | Residual plot and distribution to validate assumptions |
| Predictions | Predicts crime rates for new education values |

## Results

| Metric | Description |
|--------|-------------|
| **Slope (β₁)** | Change in crime rate per 1-year increase in education |
| **Intercept (β₀)** | Baseline crime rate estimate |
| **R² Score** | Proportion of variance in crime explained by education |
| **RMSE** | Average prediction error |

> **Note:** This is a simple univariate model. Crime rates are influenced by many factors beyond education — poverty, employment, demographics, etc. Correlation does not imply causation.
